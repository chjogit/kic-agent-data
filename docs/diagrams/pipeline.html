모든 호출은 kic_data/http_util.py를 거쳐 재시도·속도 제한을 적용합니다. API 키는 GitHub Actions Secrets에만 두며 DB와 저장소에는 저장하지 않습니다. yfinance는 Yahoo Finance의 비공식 라이브러리로 개발·연구용입니다. 각 출처의 이용 조건은 해당 기관 약관을 따릅니다.
